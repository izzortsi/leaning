# Leaning - Lab Course on Intuitionistic Type Theory and Lean

This repository contains materials for a lab course exploring **Intuitionistic Type Theory (ITT)** and the **Lean theorem prover**. The course is structured as hands-on lab sessions that connect theoretical foundations of ITT with practical implementation in Lean.

## Course Overview

Intuitionistic Type Theory, developed by Per Martin-Löf, provides a foundation for constructive mathematics and serves as the basis for many modern proof assistants, including Lean. This course explores the deep connections between ITT's theoretical framework and Lean's practical implementation.

## Structure

- **`labs/`** - Lab session notes organized by topic
- **`GRAPH.md`** - Visual representation of topic connections and learning paths

## Topics Covered

1. **Foundations** - Basic concepts of ITT and Lean
2. **Type Theory** - Types, terms, and judgments
3. **Propositions as Types** - The Curry-Howard correspondence
4. **Dependent Types** - Π-types and Σ-types
5. **Inductive Types** - Data structures and pattern matching
6. **Equality** - Propositional and definitional equality
7. **Tactics** - Proof construction in Lean
